# Devops Local Development Environment 

## 1. Project Overview

This project documents the setup and verification of a local DevOps developments on macOS running on Apple Silicon.

The environment provides tools for source control, containerization, Kubernetes, infrastructure as code, automation,cloud command-line interfaces, scripting and development.

## 2. Host Environment

- Operating System: macOS
- CPU Architecture: Apple Silicon (ARM64)
- Memory: 16 GB RAM
- Package Manager: Homebrew
- Shell: Zsh

## 3. Installed DevOps Tools

The followings tools have been installed and verified:

| Category | Tool |
| --- |--- |
| Version Control | Git |
| Code Editor |Visual Studio Code |
| Containers | Docker |
| Container Orchestration | Docker Compose |
| Kubernetes | Minikube |
| Kubernetes CLI | Kubectl |
| Kubernetes Package Manager | Helm |
| Infrastructure as code | Terraform |
| Automation | Ansible |
| JSON Processing | jq |
| JavaScripts Runtime | Node.js |
| Package Manager | npm |
| Cloud CLI | AWS CLI |
| Cloud CLI | Azure CLI |

Exact installed versions are recorded in 'tooling-verification.txt'.


## 4. Installed Method

Homebrew was used as the primary package manager for installing the majority of the DevOps tools.

The Homebrew installation can be verified with:
bash
brew --version
